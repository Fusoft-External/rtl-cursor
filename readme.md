# RTL Cursor, VS Code & Antigravity

افزونهٔ راست‌چین هوشمند برای **VS Code**، **Cursor** و **Antigravity IDE** — محیط چت، پنجرهٔ مستقل **Agents** در VS Code، دستیار هوش مصنوعی (Agent)، کامپوزر، فایل‌های Plan، **Canvas** و پیش‌نمایش Markdown، با حفظ فونت‌ها و تنظیمات خود ادیتور.

متن‌های RTL (فارسی و عربی) راست‌چین می‌شوند؛ بلوک‌های کد و واژه‌های انگلیسی **چپ‌چین** و خوانا باقی می‌مانند.

> این افزونه با ایجاد فایل بکاپ معتبر، یک لودر اختصاصی به فایل هستهٔ ادیتور (`main.js`) اضافه می‌کند. بعد از Enable / Disable یا پایان آپدیت، با تنظیم پیش‌فرض `rtlCursor.autoRelaunch` ادیتور با خروج عادی دوباره باز می‌شود؛ حتی اگر فقط در مود Agent باشید و IDE را باز نکنید. افزونه برنامهٔ در حال اجرا را اجباری نمی‌بندد.

## امکانات و ویژگی‌ها

- **تشخیص خودکار و هوشمند جهت متن (Smart BiDi):** پاراگراف‌های فارسی به طور خودکار راست‌چین و پاراگراف‌های انگلیسی چپ‌چین می‌شوند.
- **تراز بی‌نقص متن‌های ترکیبی (فارسی + انگلیسی):** جلوگیری از پریدن نقطه، علامت تعجب و عبارات انگلیسی داخل پرانتز.
- **حفظ تنظیمات فونت کاربر:** افزونه هیچ فونتی، از جمله وزیرمتن، را انتخاب یا تحمیل نمی‌کند. فونت رابط، چت، ویرایشگر، ترمینال، Canvas و پیش‌نمایش Markdown را خود ادیتور و تنظیمات کاربر تعیین می‌کنند.
- **فونت داخلی اختیاری:** فایل‌های معمولی و ضخیم وزیرمتن همراه افزونه هستند. بارگذاری آن‌ها پیش‌فرض خاموش است و روشن‌کردن آن هم تنظیمات فونت کاربر را تغییر نمی‌دهد.
- **ایزوله‌سازی دقیق کدها:** کدهای چندخطی، کلمات تک‌خطی (`code`) و ترمینال ادیتور با حفظ فونت تنظیم‌شدهٔ خودشان و جهت LTR کاملاً تفکیک شده می‌مانند.
- **پشتیبانی Canvas:** پیش‌نمایش Canvas داخل چت و تب ویرایشگر Canvas هم RTL هوشمند می‌گیرند (تزریق به iframeهای محلی `127.0.0.1`).
- **پشتیبانی VS Code:** چت بومی و پنجرهٔ مستقل **Agents**، از جمله نشست‌های Codex؛ پیام‌ها، پاسخ‌های در حال دریافت، کارت‌های سؤال و گزینه‌ها، فهرست کارها و عنوان نشست‌ها. در نسخه‌های پشتیبانی‌شدهٔ VS Code، فارسی‌نویسی کادر Monaco از موتور داخلی RTL استفاده می‌کند تا جهت متن، مکان‌نما و کلیک هماهنگ باشند.
- **پشتیبانی سه محیط:** پشتیبانی **VS Code**، **Cursor IDE** و **Antigravity IDE**، با وضعیت فعال‌سازی و تنظیم بارگذاری فونت مستقل برای VS Code.

## نصب و راه‌اندازی

شناسه افزونه: `fusoft.rtl-cursor`

### نصب آفلاین از طریق فایل VSIX:

1. فایل `releases/rtl-cursor-1.0.18.vsix` را دانلود کنید (یا از [Releases گیت‌هاب](https://github.com/Fusoft-External/rtl-cursor/releases)).
2. در ادیتور (VS Code، Cursor یا Antigravity IDE) کلیدهای **`Ctrl + Shift + P`** را فشار دهید.
3. دستور **`Extensions: Install from VSIX...`** را جستجو و فایل VSIX را انتخاب کنید.
4. روی دکمهٔ نوار وضعیت پایین صفحه کلیک کرده یا دستور **`RTL Cursor: Enable`** را اجرا نمایید.
5. ادیتور چند ثانیه بعد **خودکار بسته و دوباره باز** می‌شود تا RTL اعمال شود.

اگر از نسخهٔ قدیمی ارتقا می‌دهید و RTL از قبل فعال است، ادیتور را یک‌بار کامل ببندید و دوباره باز کنید تا لودر جدید و حذف اجبار فونت اعمال شوند.

### راه‌اندازی در محیط Agents در VS Code

افزونه را در همان VS Code نصب کنید. اگر RTL از قبل فعال نیست، دستور **`RTL Cursor: Enable`** را اجرا کنید. پس از نصب یا ارتقا، همهٔ پنجره‌های VS Code، از جمله پنجرهٔ Agents، را کامل ببندید و دوباره باز کنید؛ بارگذاری مجدد یک پنجره برای به‌روزرسانی لودر اصلی کافی نیست. پس از آن، پنجرهٔ مستقل Agents و چت داخل IDE هر دو پوشش داده می‌شوند. این پشتیبانی برای رابط بومی چت VS Code است؛ صفحه‌های وب مستقل افزونه‌های دیگر پوشش عمومی ندارند.

وضعیت و تنظیم بارگذاری فونت VS Code در پوشهٔ `.rtl-cursor-vscode` نگهداری می‌شود و فعال‌سازی یا غیرفعال‌سازی آن مراقب Cursor را تغییر نمی‌دهد. مراقب مستقل پس‌زمینهٔ ویندوز و ابزار ارتقای آن همچنان مخصوص Cursor هستند. بعد از آپدیت VS Code، اگر پچ حذف شده باشد، یک پنجرهٔ IDE باز کنید تا افزونه با تنظیم `autoReapply` آن را دوباره اعمال کند؛ سپس برنامه باید کامل راه‌اندازی مجدد شود.

برای فارسی‌نویسی در کادر پیام، نسخهٔ ۱.۰.۱۸ مسیر داخلی RTL موتور Monaco را فقط روی مدل ورودی چت فعال می‌کند. این بخش علاوه بر لودر اصلی، دو بستهٔ JavaScript مربوط به IDE و Agents را با بکاپ و checksum هماهنگ به‌روزرسانی می‌کند. دستور Disable تغییرات ورودی را هم حذف می‌کند. اگر ساختار موتور نسخهٔ VS Code شناخته نشود، فایل‌ها دست‌نخورده می‌مانند و این قابلیت فعال نمی‌شود؛ پوشش متن پاسخ‌ها مستقل است. این سازوکار به نصب Cursor یا Antigravity اعمال نمی‌شود.

### ارتقا از نسخهٔ قدیمی در مود Agent، بدون بازکردن IDE

اگر RTL از قبل فعال است و فقط در مود Agent کار می‌کنید، بعد از نصب VSIX جدید، فایل `update-agent-watcher.ps1` را از همان ریلیز دانلود و یک‌بار با PowerShell اجرا کنید:

```powershell
powershell.exe -NoProfile -File .\update-agent-watcher.ps1
```

این ابزار مراقب پس‌زمینهٔ نسخهٔ قدیمی را با بررسی هویت فرایند تعویض می‌کند و تنظیم‌ها را نگه می‌دارد. خود ابزار Cursor را نمی‌بندد. بعد از این ارتقای یک‌باره، آپدیت‌های بعدی Cursor در همان مود Agent به‌صورت خودکار پوشش داده می‌شوند. اگر IDE را باز کنید، افزونه همین ارتقا را خودش انجام می‌دهد و نیازی به اجرای ابزار نیست.

### استفادهٔ اختیاری از وزیرمتن داخلی

گزینهٔ `rtlCursor.loadBundledVazirmatn` پیش‌فرض خاموش است. با روشن‌کردن آن و اجرای `Developer: Reload Window`، فونت وزیرمتن در پنجرهٔ ادیتور و Canvas در دسترس قرار می‌گیرد؛ هیچ فونتی خودکار جایگزین نمی‌شود. برای استفاده، نام `Vazirmatn` را در تنظیمات فونت بخش دلخواه ادیتور انتخاب کنید؛ برای نمونه در `editor.fontFamily`. اثر هر تنظیم روی بخش‌های مختلف را خود ادیتور تعیین می‌کند. فونت پیش‌نمایش داخلی Markdown هم تابع تنظیمات خود ادیتور است.

برای خاموش‌کردن بارگذاری فونت داخلی، گزینه را خاموش کنید و پنجره را دوباره بارگذاری کنید. نصب یا حذف فونت در سیستم‌عامل انجام نمی‌شود.

## نکات مهم و عیب‌یابی

- **ری‌استارت خودکار:** با `rtlCursor.autoRelaunch` (پیش‌فرض روشن) بعد از Enable / Disable یا تعمیر پچ پس از پایان آپدیت، Cursor با خروج عادی بسته و دوباره باز می‌شود. بازکردن دوباره منتظر خروج کامل برنامه می‌ماند؛ اگر ذخیره‌سازی یا خروج را لغو کنید، برنامه اجباری بسته نمی‌شود.
- **ری‌استارت دستی:** اگر `rtlCursor.autoRelaunch` را خاموش کنید، مثل قبل باید از `File → Exit` استفاده کنید.
- **اعمال RTL بعد از آپدیت، بدون رفتن به IDE:** لودر RTL در پروسهٔ اصلی Electron (`main.js`) اجرا می‌شود. با `rtlCursor.autoReapply` پچ پس از پایان آپدیت دوباره اعمال می‌شود و با `rtlCursor.autoRelaunch` مراقب پس‌زمینه Cursor را با خروج عادی دوباره باز می‌کند تا پچ فعال شود. مود Agent از نشست قبلی بازیابی می‌شود؛ نیازی به بازکردن IDE یا ری‌استارت دستی نیست. اگر `autoRelaunch` را خاموش کنید یا خروج به‌خاطر پنجرهٔ باز یا ذخیره‌سازی کامل نشود، پچ با راه‌اندازی بعدی فعال خواهد شد.
- **Watch پس‌زمینه (ویندوز):** بعد از Enable یک اسکریپت مخفی در `%USERPROFILE%\.rtl-cursor\` نصب می‌شود. مراقب پس‌زمینه تا پایان آپدیت و ثابت‌ماندن فایل‌ها صبر می‌کند، پچ را به‌صورت اتمی اعمال می‌کند و در صورت روشن‌بودن `autoRelaunch` راه‌اندازی مجدد عادی انجام می‌دهد. تنظیم‌های `autoReapply` و `autoRelaunch` برای این مراقب هم رعایت می‌شوند. لانچر `wscript` است تا Windows Terminal پنجرهٔ خالی سر لاگین باز نکند. هنگام ارتقای افزونه، مراقب قدیمی با بررسی هویت فرایند جایگزین می‌شود.
- **خطای عدم دسترسی (Permission denied):** ادیتور را یک‌بار با گزینهٔ **Run as administrator** باز کرده و دستور Enable را اجرا کنید.
- **بررسی لاگ‌ها:** گزارش لودر در `%USERPROFILE%\rtl-cursor.log` و گزارش مراقب پس‌زمینه در `%USERPROFILE%\rtl-cursor-watch.log` ذخیره می‌شود.

## تغییرات نسخه ۱.۰.۱۸

- افزودن RTL واقعی برای نوشتن در کادر بومی چت و Agents در VS Code، با فعال‌کردن مسیر داخلی جهت متن در موتور Monaco.
- هماهنگی رسم متن با مکان‌نما، کلیدهای چپ و راست، تشخیص محل کلیک و جایگزینی متن انتخاب‌شده؛ بدون نوشتن جهت یا استایل روی خطوط ورودی و بدون تغییر متن پیام.
- محدودکردن مسیر جدید به مدل‌های ورودی چت VS Code؛ فایل‌های عادی، بلوک‌های کد، Cursor و Antigravity رفتار قبلی را حفظ می‌کنند.
- نگه‌داشتن جهت خط اصلی در سطرهای شکسته‌شده و ادامهٔ جهت خط قبلی در سطر خالی.
- تشخیص قابلیت موتور در هر دو بستهٔ IDE و Agents پیش از اعمال تغییر؛ نسخه‌های ناشناخته یا قدیمی بدون پچ ورودی باقی می‌مانند.
- ثبت بکاپ و به‌روزرسانی هماهنگ checksum دو بستهٔ ویرایشگر؛ غیرفعال‌سازی فقط تغییرات خود افزونه را حذف می‌کند و از بازیابی نسخهٔ قدیمی فایل‌های برنامه استفاده نمی‌کند.
- تست روی Monaco واقعی برای متن ترکیبی، جای مکان‌نما، کلیدهای جهت، کلیک و جایگزینی انتخاب؛ تست نصب، غیرفعال‌سازی، بازگردانی بایت‌به‌بایت و شکست میان‌مرحله‌ای.

این مسیر روی VS Code نسخهٔ ۱.۱۴۳.۱ بررسی شده است. بعد از نصب، همهٔ پنجره‌های VS Code را کامل ببندید و دوباره باز کنید. بارگذاری مجدد پنجره برای به‌روزرسانی لودر اصلی کافی نیست.

- Watch ویندوز با `wscript` مخفی اجرا می‌شود تا ترمینال خالی موقع روشن شدن سیستم نیاید.

- فونت دیگر اجباری نیست: Vazirmatn فقط اگر روی سیستم نصب باشد اعمال می‌شود.
- اگر کاربر فونت Cursor را عوض کرده باشد، همان فونت کاربر استفاده می‌شود.
- حذف مسیر ثابت `file://` وزیرمتن که روی سیستم‌های دیگر فونت کاربر را خراب می‌کرد.

## تغییرات نسخه ۱.۰.۱۰

- Watch پس‌زمینه روی ویندوز: بعد از آپدیت Cursor بدون باز کردن IDE (مثلاً فقط Agent Window) پچ RTL دوباره اعمال می‌شود.
- فعال‌سازی زودتر افزونه (`activationEvents: *`).

## تغییرات نسخه ۱.۰.۹

- ری‌استارت خودکار روی ویندوز بدون پنجرهٔ `cmd` / `ping` (PowerShell مخفی).

## تغییرات نسخه ۱.۰.۸

- پشتیبانی **Cursor Canvas** (پیش‌نمایش داخل چت و تب Canvas) با تزریق RTL به فریم‌های محلی.
- ارتقای لودر: `web-contents-created` + `did-frame-finish-load` + اسکن `framesInSubtree`.
- فونت وزیرمتن و تشخیص جهت هوشمند روی متن‌های Canvas.
- اطمینان از حضور کامل منطق To-do کارت Plan از نسخه ۱.۰.۷ در runtime.

## تغییرات نسخه ۱.۰.۷

- افزودن راست‌چین هوشمند برای فهرست To-do کارت Plan (`ui-todo-*` / `plan-todo__row`).
- **ری‌استارت خودکار** بعد از Enable / Disable و بعد از آپدیت ادیتور (`rtlCursor.autoRelaunch`).
- دیگر برای اعمال پچ نیازی به Exit دستی نیست؛ ادیتور خودش باز می‌شود.

## تغییرات نسخه ۱.۰.۶

- اضافه شدن پشتیبانی کامل از **Antigravity IDE** و پنجرهٔ چت و دستیار هوشمند آن (`workbench-jetski-agent`).
- افزودن فونت استاندارد **وزیرمتن (Vazirmatn)** برای متون فارسی چت و رابط کاربری.
- ارتقای موتور BiDi برای تشخیص روان‌تر پاراگراف‌های دوزبانه و جلوگیری از به‌هم‌ریختگی علائم نگارشی.
- بهبود لودر برای شناسایی خودکار مسیر افزونه‌ها در پوشه‌های مختلف کاربری.
